## Checklist

- [x] **1. Secrets + tracking hygiene.** `.env.local` and `logs/` stay untracked.
      Confirm `git ls-files` shows no keys, tokens, or personal log content.
- [x] **2. Dashboard renders.** Open `4D-tracker.html` in a real browser.
      Zero console errors. Score ring, XP bar, streaks, pillar tabs all draw.
- [x] **3. Logging works and persists.** Toggle a habit, reload the page,
      confirm the value survives via `localStorage`.
- [x] **4. Service worker can ship updates.** Current `sw.js` is pure cache-first —
      once installed, the app can never receive a new version. Fix before anyone
      installs it, or v1 is permanently frozen on every phone that adds it.
- [x] **5. Usable at 390px.** No horizontal scroll, no clipped controls,
      tap targets reachable. iPhone 14/15 logical width.
      Verified: 0px document overflow at a true 390px viewport. The pillar tab
      strip extends past the edge by design (`overflow-x:auto`, hidden scrollbar).
      Note: headless Chrome will not lay out below 500px, so a `--window-size=390`
      screenshot shows a clipped 500px render — measure in a 390px iframe instead.
      This pass surfaced stale arc content, fixed in the next commit.
- [x] **6. Install criteria met.** Manifest + registered SW + HTTPS origin,
      so "Add to Home Screen" offers a real standalone install.
- [ ] **7. Deploy to Vercel.** Project `operation-dddd` is already linked.

- [ ] **8. Verify the live URL.** Dashboard renders and logging persists on the
      deployed origin, not just localhost.
- [ ] **9. Install on the phone.** Add to home screen from the live URL,
      launch standalone, log one entry.
- [x] **10. README run + deploy steps.** Current README documents only the CLI
